# Carving and Magical Implement Craft

## Carving Table

Certain items can be placed upon a carving table and drawn on. It may be called a carving table, but no one has used a knife to cut the lines for a very long time.

:::recipe gyromancy:rune_carving_table
:::

With a magnifying glass, we can carve intricate runes into a tiny copper ring. The structures upon an item grant it special functions; combine those structures, and a magical implement is born.
