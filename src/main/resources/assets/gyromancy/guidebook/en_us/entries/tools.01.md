# Compass

## Making and Using a Compass

The compass is an auxiliary tool. It is easy to make, and helps everyone with unsteady hands finish that last stroke.

:::recipe gyromancy:compass
:::

<!-- page -->

Keep the compass in your inventory. Use it on a pen with the secondary action to store the pen inside; use it on an empty slot the same way to retrieve it. When the compass is used on an object, the first point struck becomes the center of the circle. Hold right-click and turn your view to draw an arc. Use Shift + scroll to adjust the radius. A compass selected from within the canvas can also be used to draw.
