# Finding Those Wretched Bugs

## Magic Arrays

Once the circle lights, an array can accept nothing new. Be sure to place the runes inside it beforehand.

Layered arrays permit more precise control over mana, including control along the dimension of time. Once a rune has been defined by one circle, a new circle can no longer distinguish it.

Arrays trigger in real time. When working with a dangerous inner structure, interrupt the array before it finishes forming. This requires an additional outer circle—though, of course, you could draw it on paper instead.
