# Rotation

This modifier effect supplies a vector that rotates around the final effect.

Rotation matches any $(symbol.gyromancy.loop) rune. It supplies a continuously rotating vector whose axis is the combined direction of every vector modifier and $(symbol.gyromancy.arrow) rune within it.

Note: this direction uses a fixed frame of reference and is unaffected by either the effect or the array's facing. In the absence of any $(symbol.gyromancy.arrow)-type rune, however, it instead rotates around the effect's velocity.

To the parent array, a Rotation modifier is equivalent to a single vector modifier rune, and changes continuously.
