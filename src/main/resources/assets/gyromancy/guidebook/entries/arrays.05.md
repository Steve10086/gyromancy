# 修饰法阵与适应范围

## 移动

唯一符文${symbol.gyromancy.motion}，能够适用于绝大多数的法阵，赋予效果速度和加速。少数会有不同效果。

接受${symbol.gyromancy.arrow}类符号，相加后修饰于效果。

接受自身作为修饰法阵，会作为加速度给出。
