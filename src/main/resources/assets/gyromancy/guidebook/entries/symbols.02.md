# 参数先少后多

最常用的参数是“前”。它让火焰、水流或魔力弹沿着箭头指向离开法阵。箭头的朝向和长度也会影响释放方向与力度。

其他参数会改变旋转、反向、固定、分裂或重复。它们不能随意叠加：只有中心法术愿意接纳的参数才有意义。

<!-- page -->

如果你只是想先看到法术，只放一个中心和一个“前”。多余的参数无法被当前法术接纳时，整个环会保持沉默。
