# 基础操作

## 简单好用？

放置为卷轴时不会激活内部法阵。右键卷轴仍可打开编辑界面；退出编辑界面时画布会展开并激活有效法阵。按住 Shift 放置可以直接展开，Shift + 右键收束卷轴也能直接展开。你还需要一只笔与墨水。

# 放置的方向

画布以你视角的左下角为锚点：底边永远朝向你，画布向你右手侧和远处展开，因此站在不同方向放置会占用不同的方块。墙面上的画布保持竖直；地板和天花板会随你的朝向旋转（天花板从放置者一侧抬头看时，图案是倒的）。

同尺寸的空白画布可以堆叠，一旦画上内容就无法再堆叠。创造模式下用中键点选已放置的画布，可以得到包含已识别符文结构的完整副本。

# 编辑界面

从快捷栏选中你想用的工具。

Ctrl + 滚轮 和 拖动 来控制显示大小和位置。

右侧的控制面板可以辅助画出更复杂的法阵：除了撤销、重做、清除与分辨率调整，还有一排旋转与镜像按钮（逆时针、顺时针、水平镜像、垂直镜像），整幅画布会一起变换，并且都能用撤销/重做回退。

Ctrl + Z 撤销，Ctrl + R 重做（可在「选项 - 控制 - 法阵学」中修改，默认只在画布与雕刻界面生效）。
