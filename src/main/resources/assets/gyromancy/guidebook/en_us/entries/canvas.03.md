# Saving and Recasting

## Remember to Save (You Do Not Need To)

Even after it has been drawn, an array on a canvas remains balanced and will not activate. Put the canvas down again, however, and everything begins to operate.

Altering an array while it is running will stop it.

# Every Canvas Is Independent

Placing a canvas assigns fresh identities to the runes drawn on it, so placing the same item again, or copying one canvas, never makes two canvases compete for the same effects: the arrays on each canvas run on their own.

Breaking a canvas leaves the item with the drawing and the recognized rune structure only; placing it again mints new identities and reactivates it. If the structure is missing (for example on an item from an older version), the canvas is recognized again from the drawing when it is placed.
